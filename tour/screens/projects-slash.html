🎯 One page, three steps, no surprises at the total.

Goal

Replace the four-page checkout with a single route and a stepper. Same data, fewer clicks, and a total that never changes between cart and confirmation.

/

Phases

Shell and stepper — one route, Stepper with aria-current="step", keyboard navigation.

Address and payment — one address form with autofill hints; billing defaults to shipping.

Review and place order — POST /orders, handle 429 with Retry-After backoff.

QA and rollout — checkout-qa skill on the preview, then checkout_v2 at 10% → 50% → 100%.

Checklist

Stepper with aria-current and arrow-key navigation

Address form with shipping autofill tokens

Billing same as shipping by default

Place order wired to the orders API

Persist the current step in the URL (?step=)

Error states on AddressForm

Run checkout-qa on the preview build

Turn on checkout_v2 for 10% of traffic

Risks

Payment element mounts slowly on low-end Android (88 ms on the preview, budget 300 ms).

Cart rounding fix must land first, or the review total can differ from the cart by a cent.
