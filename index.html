Before you paste that

Read the script first. Piping anything to bash means trusting whoever wrote it and wherever it is hosted. Slate's installer is short, commented, and explains every step it takes — read it.
Why a script and not a .dmg. Slate is not notarized by Apple yet. macOS quarantines anything a browser downloads, and for an un-notarized app that becomes a "could not verify this app" dialog you can only clear from System Settings. Quarantine is applied by the downloading app, and curl doesn't set it — so installing this way just works, without asking you to turn off a security control. Updates are cryptographically signed either way.
What is actually verified. The installer checks the download against the release's SHASUMS256.txt — but that file and the tarball come from the same host, so it catches a corrupted download rather than a compromised one. Updates are different: Slate ships a minisign signature with every release and verifies it against a public key compiled into the app, so it refuses anything the key doesn't match. Your first install is trust-on-first-use; every update after it is checked against a key already on your machine. Notarization is what would close the first-install gap, and it isn't done yet. 
# check a download yourself, before installing
shasum -a 256 -c SHASUMS256.txt
Apple Silicon only, for now. The installer checks first and tells you, rather than installing something that won't run.
