What it is

One file, on your Mac

Your whole workspace is a single SQLite file. No account, no sync, no telemetry. It works on a plane.

Shared memory for every AI tool

Slate is an MCP server. What Claude Code learns on Tuesday, Cursor knows on Wednesday.

Pages and a block editor

Nested, typed pages — projects, repos, branches, plans, designs — in a keyboard-first editor.

An agent that runs on your CLI

The in-app agent uses the Claude Code or Gemini CLI you already have. No API keys.

Connects itself

Claude Code Cursor Codex Gemini

On first launch Slate registers itself as an MCP server with whichever of these it finds installed. No config files to edit, no paths to paste.

After you install

  1. Slate opens and creates your workspace.
  2. It connects to the AI tools it finds. Nothing to configure.
  3. Restart those tools. They can now recall and remember against your workspace.
  4. Updates arrive in-app: Settings → About → Check for updates.

Before you paste that

Read the script first. Piping anything to bash means trusting whoever wrote it and wherever it is hosted. Slate's installer is short, commented, and explains every step it takes — read it.
Why a script and not a .dmg. Slate is not notarized by Apple yet. macOS quarantines anything a browser downloads, and for an un-notarized app that becomes a "could not verify this app" dialog you can only clear from System Settings. Quarantine is applied by the downloading app, and curl doesn't set it — so installing this way just works, without asking you to turn off a security control. Updates are cryptographically signed either way.
Apple Silicon only, for now. The installer checks first and tells you, rather than installing something that won't run.

Slate is in alpha. Your data stays on your machine.
