What was checked

  • 89 real coding sessions on one developer's Mac, over the same weeks in August 2026 — the same AI model and the same memory instructions in every one.
  • Only sessions that owed a memory were counted: real work on a git branch, where the instructions asked the AI to save what it learned before finishing.
  • The only difference was Slate's end-of-turn hooks. Without them, 3 of 43 sessions saved their work. With them, 35 of 46 did.
  • Saved means written back to memory — a decision, a lesson or progress filed on the branch — not just mentioned in the chat.

Why Slate

Every AI tool starts from zero.
Today, you are the memory.

It forgot yesterday

Each session starts blank. What Claude Code worked out on Tuesday, Cursor has never heard of on Wednesday — so you explain it again.

Five terminals, one of them waiting

Sessions run in different tools and folders. The one that stopped to ask you a question has been sitting there for twenty minutes.

The busywork never stops

Standups, reviews, the ticket you owe a reply. None of it happens unless you do it, and none of it is the work you sat down to do.

Slate fixes it the way your own memory works: it notices, remembers, recalls and acts — for every AI tool at once, on your Mac, in files you own.

  1. 1

    It notices everything

    Every session from every AI tool is captured as it happens, from the transcripts the tools already write. Nothing to remember to do, nothing to paste.

  2. 2

    It remembers what lasts

    Decisions with their reasons, preferences, lessons, where each branch stands — each tied to the file it's about, and flagged when that code changes.

  3. 3

    It hands it back on time

    When any tool starts a task, the right memory is already there — whichever tool you open next. Not when you think to ask: when the work needs it.

  4. 4

    It works while you're away

    Agents run your standup, debrief each session and draft the reply you owe — on the AI tool you already pay for, inside rules you set.

Why "Slate"? A slate is the clapperboard that syncs separate cameras onto one timeline. Your AI tools are the cameras.

Yours, on your Mac

Local-first isn't a setting. It's the design.

Files you own

Every workspace is a SQLite file on your machine. Copy it, back it up, open it in any SQLite browser.

No account

Everything works without signing in. Sign in only when you want to share a workspace with a team.

No API keys

Slate drives the AI CLIs you already signed in to. It holds no key and calls no model itself.

Nothing leaves by surprise

Four exceptions, each named in the docs: your AI tool's own calls, sharing you turn on, the update check, and opt-in usage counts.

Usage counts are opt-in

Off until you turn them on — and never your pages, conversations or file paths.

An open protocol

Memory is served over MCP, so any MCP-aware tool can read and write it — not just the five Slate knows.

Questions

Before you install.

Does it cost anything?

Not during the alpha — there is no licence, key or trial to activate today. Slate will become a paid product soon, and the pricing will be announced here before it starts. What you have written stays yours either way: it lives in files on your Mac.

What do I need?

A Mac — Apple Silicon or Intel — and at least one AI coding CLI — Claude Code, Codex, Gemini, Cursor or OpenCode — already signed in. Linux and Windows are not in the latest release yet.

Does Slate send my code or conversations anywhere?

No. Slate reads the transcripts your tools already write and keeps them on your Mac. Your AI tool still talks to its own model under its own sign-in, as it always did. A workspace you choose to share is readable by its members; Personal never is. The four exceptions, precisely.

What does it change in my AI tools?

Nothing until you connect one. Connecting installs Slate as a plugin in Claude Code and Codex, and as an MCP server in Gemini, Cursor and OpenCode. Every file is copied aside before it is changed, and turning a tool off takes out what Slate put there.

Why a curl script and not a .dmg?

Slate is not notarized by Apple yet. macOS quarantines anything a browser downloads, and for an un-notarized app that becomes a "could not verify" dialog you can only clear in System Settings. curl sets no quarantine flag, so the app simply opens. The script is short and commented — read it first.

What does the installer verify?

The download against the release's SHASUMS256.txt — which catches a corrupted download, not a compromised host, since both come from the same place. Updates are stronger: each is signed, and Slate checks the signature against a key built into the app before installing.

# check a download yourself
shasum -a 256 -c SHASUMS256.txt
How do updates work?

Slate checks while it is open, downloads a new version in the background and installs it when you next quit. Nothing restarts on its own.

How do I remove it?

One command takes Slate out of every AI tool it was connected to and removes the app. Your workspace is kept unless you ask otherwise, and --dry-run shows every step first.

curl -fsSL https://liozelmalem-star.github.io/slate-releases/uninstall.sh | bash -s -- --dry-run
Can my team use it together?

Yes, optionally. A shared workspace is a separate file that its members read; your Personal workspace never syncs. Each page has one author and opens read-only for everyone else. Sharing is off until you sign in.
