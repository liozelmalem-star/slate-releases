Use Slate

One page for each place in the app, with Sessions, Memory and Toolkit first.

SessionsEvery AI-CLI session on this machine, live. Who is working, who needs you, where each runs, and what each changed.MemorySlate's memory is shared by every agent through an MCP server, filled in automatically, and stored as docs you can read and fix.ToolkitWrite your instructions and skills once, then sync them to your agents from one source.HomeHome, Slate's in-app AI agent: it reads and writes your workspace, reaches the MCP tools you connect, and does its routing in code so a light model works.TasksTasks — what waits on you, in four sections (To-dos, Issues, Reviews, Messages), plus today's meetings, reminders, agent runs and receipts.Docs and the block editorEverything in Slate is a doc: nested, typed, and edited in a keyboard-first block editor. Covers the editor, the doc tree, Code, Trash, and the group and project docs.AutomationsAutomations work for you on a trigger, inside rules you set. Give one a job, reply in its thread, and say yes or no before it changes anything.ArtifactsWhat your agents publish for you: an HTML page, chart, report or Markdown note, kept in your workspace with every version.Activity and analyticsYour AI sessions over time: the dashboard, where its numbers come from, and how far back it reaches.ConnectThe screen for how a workspace reaches outside itself: which agents it runs, which apps it connects, and what it can import from other tools.WorkspacesA workspace is one store, shared or private. Switch into one from the top of the rail and the whole app works inside it.Search and command palettePress ⌘K to run an action, jump to a doc or search your workspace. Also the cheatsheet, rebindable shortcuts, the sidebar, the rail and tabs.TrashDocs and widgets you move to Trash stay there until you restore them or delete them forever.ThemesSlate's two themes, Mint and Forest, the brand colour, the workspace palette and the interface zoom.
