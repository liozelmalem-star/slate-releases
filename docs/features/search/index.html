Features

Search & Command Palette

The command palette is the fastest way through Slate. Press ⌘K anywhere and a single input does three jobs at once: run a command, jump to a page, or search the full text of your workspace.

What ⌘K does

ModeWhat it does
Run actionsTrigger app commands — create a page, switch panes, toggle settings — without hunting through menus.
Jump to a pageStart typing a title and go straight to it.
Full-text searchSearch across page titles and bodies and open a result.

Full-text search is backed by SQLite FTS5 (migration 016), an index over your page titles and bodies. Because it's a local index in the same SQLite file as your content, search stays fast and never leaves the machine.

⌘K searches your workspace only. What other people shared is searched separately — by opening the Workspaces, or by an AI tool calling recall_workspaces. Keeping them apart is deliberate: private and shared results have different trust, and a palette that blended them would leave you unable to tell which you were looking at.

Sessions in ⌘K

Every live AI session on the machine is a row: with nothing typed, up to five under Live sessions, the one waiting on you first; typed, a session matches by its title, its project, its branch or its tool (fix/ finds the agent on that branch). Enter opens it in the Sessions tab, as a chip in that tab's own strip — the live terminal where Slate can attach or branch, the transcript where it cannot. On a page that stands for a folder, Start a session here launches on the project's default tool. Fork, Stop and the resume command live on the session's own header in that tab, not in the palette.

The cheatsheet

Press ? at any time to bring up the keyboard cheatsheet — a reference of the shortcuts available in the current context, so you don't have to memorize them.

Rebindable shortcuts

Shortcuts are yours to change. Settings → Keyboard lists every command the palette knows; click its key to record a new one, and a key another command held moves over. Unbind takes a key away, Reset puts the default back. The palette and the cheatsheet read the same registry, so a change here shows up in both at once. One key per command — there are no multi-key sequences.

Tabs

The main area is tabs (pages and sessions alike), and the strip answers to what an editor's does:

⌃⇥ / ⌃⇧⇥Walk the tabs by recency while ⌃ is held — once is the tab you were just on, twice is the one before that
⌘1‥⌘9The nth tab; with fewer than n open, the last one
⌘WClose. A pinned tab refuses — unpin it first
⌘⇧TReopen the tab closed most recently (pages, not sessions)
⌘⇧JThe session that has waited on you longest; again for the next
⌥⌘← / ⌥⌘→Move the tab along the strip
⌘⇧D, ⌘-clickOpen the tab beside the current one; ⇧⌘\\ closes the split
DragReorder. Pinned tabs stay at the front
Middle-clickClose
Right-clickPin, open beside, close, close others, close to the right

Open page tabs come back after a restart, in their order, pinned where they were — and per workspace: each one remembers its own strip, so switching workspace changes the strip the way it changes the page tree. Up to twenty come back; session tabs come back through the sessions themselves. A strip too wide for its box gets a chevron at the end listing everything open.

Search only covers pages. Captured AI sessions are stored as pages too, so they show up in results alongside everything else — see Session Capture.
