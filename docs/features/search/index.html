Features

Search & Command Palette

Press ⌘K anywhere. One input runs a command, jumps to a doc, or searches your workspace: doc titles and bodies, tasks, memories, reports and artifacts. Search uses SQLite FTS5, an index in the same local file as your content. It never leaves the machine.

⌘K searches your workspace only. What others shared is searched by opening Workspaces, or by an agent calling recall_workspaces. Private and shared results have different trust, so the palette never blends them.

Captured AI sessions are docs, so they appear in results too. See Session Capture.

What ⌘K lists

With nothing typed, ⌘K shows Open tabs, Live sessions, Recent and Favorites, then five places under Quick navigation.

When you type, the order is: Actions (commands whose name holds the text), open tabs, Go to (places and a few Settings sections), sessions, files, Docs, Tasks (to-dos and tickets, open in Tasks), Memories (open in Memory), Reports and Artifacts. Commands that match loosely come last, under More actions.

Files come from the open workspace's projects only. A doc row shows its parent path, so three docs called "Notes" can be told apart. A doc in Trash is marked In Trash and opens read-only, with Restore.

Text inside files — ⌘⇧F

⌘⇧F (Search docs and files) searches doc bodies and, below them, the text inside the files of every project and worktree in the open workspace. A file hit is the matching line with its file and line number, grouped by checkout and branch. Enter opens the file, read-only, at that line.

The query starts at three characters. It is plain text, not a pattern, and case does not matter. Ignored files and binary files are skipped. Files an agent wrote but did not commit are included. At most 200 lines are found, and the palette shows the first 30.

Sessions in ⌘K

Every live AI session on the machine is a row. With nothing typed, up to five show under Live sessions, those waiting on you first. Typed, up to four match by title, project, branch or tool (fix/ finds the agent on that branch). Enter opens it as a chip in the Sessions tab strip: the live terminal where Slate can attach or branch, the transcript where it cannot.

On a doc that stands for a folder, Start a session here launches on the project's default tool. Second session here, Continue in a copy, Stop and the resume command are on the session's own header, not in the palette.

Web pages in ⌘K

Type a web address and the first row is Open in Slate. It opens the web page in Slate's own browser, as a tab. It accepts a full address (https://example.com/docs), a local server with port (localhost:3000), a bare domain (example.com, opened over https) and the full path to an HTML file (/srv/site/index.html). Ordinary words, file names such as index.html and versions such as v1.2 go to normal search.

The tab is read-only: back, forward, reload, an address bar, and a button that opens the web page outside Slate. Back and forward follow addresses you typed in the bar, not links you clicked in the web page. Many public sites refuse to show inside another app. The tab says so and offers your browser. Your browser's sign-ins do not carry over.

A local HTML file is served from its own folder on a private local port, so its scripts, styles and images load. Files and folders below it whose names start with a dot (.env, .git) are never served. The web page may connect nowhere but that folder, so a downloaded web page cannot send its neighbours away or pull a script from the internet.

A local server's address in a session's messages or terminal opens in this browser too, beside the session.

The cheatsheet

Press ? for the shortcuts of the current context, including ⌘N new doc, ⌘⇧G generate a doc, ⌘⇧N quick capture and ⌘F find in doc. The palette opens it too, as Keyboard shortcuts. Tooltips read the same list, so they follow a key you rebind.

Rebindable shortcuts

Settings → Keyboard lists every command the palette knows. Click a command's key to record a new one. A key another command held moves over, and a note ("⌘X moved from A to B.") offers Undo. Unbind takes a key away. Reset restores the default. The palette and cheatsheet read the same registry. One key per command, with no multi-key sequences.

The sidebar

The icons down the left edge are always there. Beside them is the sidebar, the list for the section you are in. It is pinned or hidden, and Slate remembers which.

With the sidebar hidden, rest the pointer on an icon and that section's list floats out over the doc without moving it. Move to another icon and the list changes. Move away, press Escape or click elsewhere and it slides back. With the sidebar pinned, an icon shows only its name.

Choosing a section never pins or hides the sidebar. Three things do:

  • clicking the icon of the section you are already in
  • ⌘\\
  • the sidebar button at the top of the list

While a list floats, ⌘\\ and that button pin it and take you to its section.

Every icon with a list works this way. Picking a conversation from the floating Home list opens it in Home. Activity's panel holds the project picker, the range and saved views, and floats out the same way. Trash has no list, so it shows only its name.

The rail

Read the rail top to bottom. Sessions comes first, on its own tile: every AI session on this computer, drawn as an orbit with a dot per session that is working or waiting, in its workspace's colour. When a session starts, stops, or starts or stops waiting on you, the dots go once round. A working dot breathes, a waiting one grows and stays larger. Otherwise they hold still.

A short line separates Sessions from the workspace: its tile (the workspace's mark in its colour, name on hover), then Home, Projects, Tasks and the rest, with Connect and Trash as round buttons at the foot. A second short line sets Settings apart, last. Outside the lines, things are the same in every workspace. Between them, everything belongs to the open one. Your account, signing in and the docs are in Settings.

Where you are sits on a filled tile and is the only icon drawn in colour. The workspace's own icons wear its colour, like its tile. Sessions and Settings wear Slate's five colours. While one of them is open, the workspace tile turns grey too, unless Sessions is narrowed to the workspace you are in. In a short window, what does not fit folds into More.

Tabs

The main area is one strip of tabs in every world. It holds docs and everything the Sessions world opens: sessions, terminals, files, a branch's changes and previews.

A click opens a temporary tab. Its title is italic, and the next thing you open replaces it. That goes for a doc in the sidebar and for a row, file or branch in the Sessions list. The tab is kept when you:

  • edit the doc (body, title, icon, cover or status)
  • double-click the tab, or the doc in the sidebar
  • choose Keep open or Pin from the tab's right-click menu
  • open it beside the current tab (⌘-click)

A doc you create or duplicate opens kept, and so does a session you launch.

Shortcuts with ⌘ or ⌃ work while you type. A shortcut on a bare key, or on ⌥ alone, waits until you stop typing, because ⌥ plus a key types a character.

⌃⇥ / ⌃⇧⇥Walk the tabs by recency while ⌃ is held: once is the tab you were just on, twice is the one before
⌘1‥⌘9The nth tab; with fewer than n open, the last one
⌘WClose. A pinned tab refuses: unpin it first
⌘⇧TReopen the tab closed most recently
⌘⇧JThe session that has waited on you longest; again for the next. After the sessions come the tasks waiting on you, then back to the first session
⌥⌘← / ⌥⌘→Move the tab along the strip
⌘⇧D, ⌘-clickOpen the tab beside the current one, such as a session beside its plan doc. ⇧⌘\\ closes the split. ⌘-click works on a doc in the tree, in Favorites and Recents, and on a link in a doc. A doc's right-click menu has Open beside too
Double-clickKeep a temporary tab open
DragReorder. Pinned tabs stay at the front
Middle-clickClose
Right-clickKeep open, pin, open beside, close, close others, close to the right, close all. Every close spares pinned tabs

When two open tabs share a title (two projects each with a doc called README), each also shows its parent doc's name in grey. ⌘K lists open tabs first, most recently shown first, and does not list them twice.

Closing the tab of a session Slate runs asks whether to end it or keep it running. See Sessions. The tab beside it of the same kind takes its place, so closing a session never moves you out of the Sessions world. A session that ends takes its tab with it.

Open tabs come back after a restart, in order, with pinned and kept state, and per workspace: each remembers its own strip. Up to twenty come back. A session tab comes back only while its session still runs. A strip too wide for its box gets a chevron at the end listing everything open, and the tab you switch to scrolls into view.
