Features

Search & Command Palette

The command palette is the fastest way through Slate. Press ⌘K anywhere and a single input does three jobs at once: run a command, jump to a page, or search the full text of your workspace.

ModeWhat it does
Run actionsTrigger app commands — create a page, switch panes, toggle settings — without hunting through menus.
Jump to a pageStart typing a title and go straight to it.
Full-text searchSearch across page titles and bodies and open a result.

Full-text search is backed by SQLite FTS5, an index over your page titles and bodies in the same local file as your content, so it stays fast and never leaves the machine.

⌘K searches your workspace only. What other people shared is searched separately — by opening the Workspaces, or by an AI tool calling recall_workspaces. Keeping them apart is deliberate: private and shared results have different trust, and a palette that blended them would leave you unable to tell which you were looking at.

Captured AI sessions are stored as pages, so they turn up in results alongside everything else — see Session Capture.

Text inside files — ⌘⇧F

⌘⇧F (Search pages and files) searches page bodies and, below them, the text inside the files of every repository and worktree Slate tracks. A file hit is the matching line, with its file and line number under it, grouped by the checkout and branch it is in — the same file exists in every worktree. Enter opens the file, read-only, at that line.

It starts at three characters. The query is plain text, not a pattern, and case does not matter. Files the repository ignores and binary files are skipped; files an agent has written but not committed are included. At most 200 lines are found, and the palette shows the first 30.

Sessions in ⌘K

Every live AI session on the machine is a row: with nothing typed, up to five under Live sessions, the one waiting on you first; typed, a session matches by its title, its project, its branch or its tool (fix/ finds the agent on that branch). Enter opens it in the Sessions tab, as a chip in that tab's own strip — the live terminal where Slate can attach or branch, the transcript where it cannot. On a page that stands for a folder, Start a session here launches on the project's default tool. Fork, Stop and the resume command live on the session's own header in that tab, not in the palette.

Web pages in ⌘K

Type a web address and the first row is Open in Slate. It opens the page in Slate's own browser, as a tab in the strip. It understands a full address (https://example.com/docs), a local server with its port (localhost:3000), a bare domain (example.com, opened over https), and the full path to an HTML file on this machine (/srv/site/index.html). Ordinary words, file names such as index.html, and versions such as v1.2 are left to the normal search.

The browser tab is read-only. It has back, forward, reload, an address bar you can type a new address into, and a button that opens the page outside Slate. Back and forward follow the addresses you opened from the bar, not links you clicked inside the page. A local HTML file is served from its own folder on a private local port, so its scripts, styles and images load. Many public sites refuse to be shown inside another app and stay blank; the tab says so and offers your browser. Signed-in sessions from your browser do not carry over.

A local server's address in a session's messages or its terminal opens in this browser too, beside the session.

The cheatsheet

Press ? at any time to bring up the keyboard cheatsheet — a reference of the shortcuts available in the current context.

Rebindable shortcuts

Shortcuts are yours to change. Settings → Keyboard lists every command the palette knows; click its key to record a new one, and a key another command held moves over. Unbind takes a key away, Reset puts the default back. The palette and the cheatsheet read the same registry, so a change here shows up in both at once. One key per command — there are no multi-key sequences.

The sidebar

The icons down the left edge are always there. Beside them is the sidebar: the list for the section you are in. It is either pinned or hidden, and Slate remembers which.

With the sidebar hidden, rest the pointer on an icon and that section's list floats out over the page. The page does not move. Move to another icon and the list changes; move away, press Escape or click elsewhere and it slides back. With the sidebar pinned, an icon shows only its name: the list on screen stays the one you chose.

Choosing a section never pins or hides the sidebar. Three things do:

  • clicking the icon of the section you are already in
  • ⌘\\
  • the sidebar button at the top of the list

When a list is floating, ⌘\\ and that button pin the list you are looking at, and take you to its section.

Every icon with a list works this way. Picking a conversation from the floating Console list opens it in Console. Activity and Trash have no list, so they only show their name.

Tabs

The main area is one strip of tabs, in every world. It holds pages and everything the Sessions world opens: sessions, terminals, files, a branch's changes and previews. It answers to what an editor's strip does.

A click opens a temporary tab. Its title is in italics, and the next thing you open takes its place instead of adding a tab. That goes for a page in the sidebar and for a row, a file or a branch in the Sessions list. The tab is kept, and stops being replaced, as soon as you:

  • edit the page — its body, title, icon, cover or status
  • double-click the tab, or the page in the sidebar
  • open it with ⌘-click, from the sidebar or a link in a page
  • choose Keep open or Pin from the tab's right-click menu
  • open it beside the current tab

A page you create or duplicate opens kept, and so does a session you launch.

Shortcuts that hold ⌘ or ⌃ work while you type in the editor or a text field. A shortcut on a bare key, or on ⌥ alone, waits until you are not typing, because ⌥ plus a key types a character.

⌃⇥ / ⌃⇧⇥Walk the tabs by recency while ⌃ is held — once is the tab you were just on, twice is the one before that
⌘1‥⌘9The nth tab; with fewer than n open, the last one
⌘WClose. A pinned tab refuses — unpin it first
⌘⇧TReopen the tab closed most recently
⌘⇧JThe session that has waited on you longest; again for the next
⌥⌘← / ⌥⌘→Move the tab along the strip
⌘⇧D, ⌘-clickOpen the tab beside the current one — a session beside its plan page, say; ⇧⌘\\ closes the split
Double-clickKeep a temporary (italic) tab open
DragReorder. Pinned tabs stay at the front
Middle-clickClose
Right-clickKeep open, pin, open beside, close, close others, close to the right, close all. Every close spares pinned tabs

When two open tabs have the same title — every repo has a branch page called main — each also shows its parent page's name in grey. ⌘K lists your open tabs first, most recently shown first, so a page you already have open is one keystroke away and is not listed twice.

Closing the tab of a session Slate runs ends the session, after asking — see Sessions. When a tab closes, the tab beside it of the same kind takes its place, so closing a session never moves you out of the Sessions world. A session that ends takes its tab with it.

Open tabs come back after a restart, in their order, pinned and kept where they were — and per workspace: each one remembers its own strip. Up to twenty come back. A session tab comes back only while its session is still running. A strip too wide for its box gets a chevron at the end listing everything open, and the tab you switch to always scrolls into view.
