Features

Memory

Slate's memory is shared by every AI tool you use, and it is stored as pages you can read.

Three parts make that work:

  • Slate is an MCP server. Any tool that speaks MCP — Claude Code, Cursor, Codex, Gemini, OpenCode — starts a session with the project's memory index, searches with recall, and saves with remember. One workspace, many tools.
  • A watcher fills it in. It reads the conversation files your AI tools already write, stores each session as a page, and reads the memory folders Claude Code, Gemini CLI and Codex keep for themselves.
  • Memory is your pages. Sessions, decisions and facts live in the same local SQLite workspace as everything else. When something is wrong, open the page and fix it, and the next recall reads the correction.
