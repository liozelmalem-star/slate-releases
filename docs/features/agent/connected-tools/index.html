Connected MCP Tools

The Console isn't limited to Slate's own workspace tools. It can reach out to any MCP server you connect, giving the agent access to whatever those servers expose.

Where servers come from

The Console does not keep its own MCP server list. When a turn is handed to the brain's CLI, that CLI loads the MCP servers declared in its own config — the account's, and the project directory's — and reports back which ones connected. Which account a tool runs under is Connect → AI tools, and a project may override it; which servers that account declares is the CLI's own config.

Two directions — don't conflate them

Slate sits on both sides of MCP, and it's worth being precise about which is which.

DirectionWhat it means
Slate as an MCP serverSlate exposes your workspace to other AI tools (Claude Code, Cursor, Codex, Gemini, OpenCode). Those tools call into Slate.
The Console reaching other serversThe in-app agent calls out to MCP servers you connect. Slate is the client.

This page is about the second direction. The first — Slate exposing your pages and memory to everything else — is its own feature.
