Connected MCP tools

View as markdownOpen the .md copy of this page

Home reaches whatever MCP servers your agent's CLI can reach. This guide covers that direction, with Slate as the client; for the other, see Slate as an MCP Server.

Where servers come from#

Home keeps no server list. The CLI loads the servers in its own config (the account's and the project directory's) and reports which connected. Connect → Agents sets the account a tool runs under (a group or project may override it); edit its servers where the CLI keeps its config. The top bar's tools chip shows the count the CLI reported, names on hover, · 1 failed in amber, and keeps it after the turn (details).

Apps you connected in Slate#

An app connected in Connect → Integrations (Linear, Notion, Jira…) is readable from every session, even when the tool's config has no server for it, while Slate is open. connected_tools lists the apps and their read-only tools; read_connected reads through one with Slate's own sign-in. Tools that write are never offered. See Slate's MCP tools.
