Features by AI Tool

Slate works with five AI tools. They do not all offer the same things, so Slate keeps one table of which tool has which feature. Every control that depends on a tool reads this table. If a tool cannot do something, the control is hidden or disabled with a reason. It is never shown doing nothing.

Each cell is one of four answers:

  • yes — Slate does it on this tool today.
  • not yet — the tool can do it, and Slate does not use it yet.
  • unverified — it may already work, and nobody has run it to check.
  • no — the tool has no way to do it. Slate records what was measured and on which day.

Measured on 2026-09-19 against Claude Code 2.1.278, Codex 0.142.3, Gemini 0.58.0, Cursor's cursor-agent 2026.09.15 and OpenCode 1.18.31. The CLIs change often, so a "no" is a measurement with a date. It is not a permanent limit.

Why some cells are "no"

Every "no" was checked against the tool's official documentation on 2026-09-19. A cell stays "no" only when the docs offer no way to do it.

  • Budget caps and fallback models exist only in Claude Code. Gemini has a turn cap and switches from Pro to Flash on its own when rate-limited, but none of the four has a spend cap.
  • Background sessions that keep running after you close them: Codex and Gemini have no local way to detach a session. Codex's cloud exec runs on OpenAI's servers, and Slate keeps work on your machine.
  • Structured output (an answer that must match a schema): Gemini and Cursor print a fixed JSON shape only.
  • Choosing a session's id before it starts: Codex and OpenCode always create the id themselves.
  • Listing running Gemini sessions: Gemini lists saved sessions, not running ones.
  • Native memory: Cursor's Memories live only in the editor's settings, and OpenCode has no memory feature of its own.
  • OpenCode's end-of-turn save check: its plugin events all fire after the turn has ended, so nothing can hold the turn open.

Gemini cells marked "not yet" were read from the documentation. On a consumer account, Gemini stops before any turn with IneligibleTierError (see Brains), so they cannot be checked on such a machine.

The table lives in code, in packages/shared/src/tools/features.ts, together with the evidence for every "no". A test fails if this page and the code disagree.
