Apps

A app is a small app that runs inside Slate: a review queue, a weekly chart of your sessions, a form that files tasks. You describe it, your AI tool writes it, and it appears beside the chat that made it. You can change it by asking again, or by editing its files.

An app is an artifact with a place of its own: the Apps tab on the rail, beside Artifacts, with every version kept. The decision behind it is ADR 0077.

Making one

  1. In Apps, choose New app.
  2. Say what it should do, in your own words.
  3. Your project's AI tool builds it. The chat on the left tells you what it is doing, and the app on the right changes each time a new version builds.

Nothing opens in Sessions. The work runs in a session Slate keeps in the background, under your own AI tool and account. See the full session opens it if you want to look.

An app belongs to a project, and reads only that project.

Using and changing one

Pick an app in the list and it opens as a builder of its own. The list steps aside; ‹ Apps brings it back. The bar shows the app's name, three views in the middle, the chat button, the versions and ⋯. The chat sits on the left and stays through all three views:

  • Preview — the app, updating as the chat works, with Reload and Full size (Esc returns).
  • Code — the app's folder: a tree and an editor. Add a file (a path like lib/format.ts makes its folder), remove one, and press Save (⌘S).
  • As you type, the editor offers what can come next: after slate. the calls, inside <Button its props, with each one's description beside the list.
  • Format (⇧⌥F) lays the open file out the way VS Code does; the brush above the tree formats every file. Nothing is formatted on save.
  • Diff shows the open file against the version before, and puts a change back as an ordinary edit. Blame shows, line by line, which version wrote it.
  • Select lines and press the speech bubble to ask the chat about them.
  • Slate checks the app's types and builds it. If either fails, nothing is saved: your edits stay, and each error opens its file at its line. Only the newest version of your own app can be edited.
  • Data — what the app keeps of its own, key by key, and how much of its 1 MB it uses. Edit a key's value (it must be JSON) or Clear it; a running app sees the change after Reload. Then what it asked for and what you allowed. ⋯ → Permissions opens it too.

The chat

Ask in the chat for anything else: "make the buttons green", "add a filter for this week". The same chat goes on while its session is open; New chat starts over. The chat button hides it.

  • Every version stays in the chat, with who made it: your AI tool, or you with a save in Code. Restore brings an older one back as the newest, so nothing is lost. When a session ends, what you asked and each version stay; the AI's own words are in the session, under See the full session while it runs.
  • Ideas for what next. The AI ends each answer with up to three ideas. Each is a button that asks for it.
  • Build or Discuss. Under the box, Discuss talks a change through and changes nothing. Build it then asks for what it planned.
  • Fix with AI. When the app no longer type-checks, or stops on an error while it runs, a note above it says where, and Fix with AI sends the error to the chat.

When Apps opens on an app by itself, because it is the newest one, the list stays. A link that names an app under Artifacts (from ⌘K, Activity or a tool) opens it in Apps.

What it can do

It reads freely inside its project:

  • pages, and what each one is (a project, a branch, a document), so it can draw the tree
  • memories
  • AI sessions, their counts per day and per tool, and the ones running right now
  • AI runs: which tool and model, how long, how many tokens, and what they cost
  • git activity in the project's folders: commits, branches made and switched, files staged
  • the project's artifacts, which it can open in Slate
  • routines

It sees only its own project: activity in a folder with a similar name, or a session in another project, is not there. It keeps its own data on this Mac (up to 1 MB), never synced.

Anything else needs a permission, which the app lists in its slate.json with a reason. Slate asks you the first time, on a card it draws outside the app:

PermissionWhat it allows
Read your TasksEvery open item in Tasks.
Change your TasksAdd your own items, set reminders, mark items done.
Save memoriesSave memories in this project. Every AI tool can recall them.
Write pagesMake pages and add text to pages in this project.
Run routinesRun a routine. Slate asks you each time, naming it.
Open AI sessionsOpen a session with a prompt typed in. You press Send.

Even when allowed, a memory or page write shows you its words on a card before anything is saved. Permissions lists what the app asked for and lets you take any of it back. An app cannot delete anything.

What it cannot do

  • Reach the internet. No requests, sockets, images, fonts or scripts from anywhere. No WebRTC, no resource hints, no frames, no popups. If it tries to leave for another address, Slate closes it.
  • Read outside its project, or anything of a teammate's.
  • Act on its own where it matters: a routine, a session, a memory or page text all wait for you.

In a shared workspace, a teammate sees your app as its built page, with nothing answered: it never reads their store, and its reads fail at once saying so. They get Preview and Code, read-only, and no chat or Data.

When Slate updates

An app may name the SDK version it was made for in slate.json ("sdk": 1). Within a version Slate only adds calls and parts. When you open your app, Slate checks its code against this version of Slate; if it no longer fits, a note above the app says where, and the chat can fix it.

For the AI tool building it

An app is index.html with <script type="module" src="./App.tsx"></script>, then .tsx .ts .jsx .js .css .json .md .svg files in any folders. It may import its own files and react, react-dom/client, lucide-react, @slate/sdk (the calls), @slate/sdk/react (useQuery, useStore) and @slate/ui (Slate's own buttons, inputs, cards, rows and states, in both themes). The tool sends files with publish_artifact; get_artifact on an app returns its files and the whole API as sdk: TypeScript declarations, the same ones Slate checks every build against. The calls are listed in App API.

Limits

  • Up to 300 files per app.
  • An app's own data: 1 MB.
  • A toast at most once a second.

Slate is in alpha. Your data stays on your machine.
