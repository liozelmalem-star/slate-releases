Keyboard shortcuts

View as markdownOpen the .md copy of this page

This guide lists every keyboard shortcut Slate has. Press ? anywhere for the shortcuts of the current context, or open Settings → Keyboard to change one.

Keys are written for a Mac. On Windows and Linux, ⌘ is Ctrl. Shortcuts with ⌘ or ⌃ work while you type. A shortcut on a bare key, or on ⌥ alone, waits until you stop typing, because ⌥ plus a key types a character.

Rebind a shortcut#

Settings → Keyboard lists every command in the palette. Click a command's key to record a new one. A key another command held moves over, and a note ("⌘X moved from A to B.") offers Undo. Unbind takes a key away; Reset restores the default. One key per command, no multi-key sequences. The palette, the cheatsheet and tooltips read the same list, so they follow a key you rebind. The shortcuts in the tables below marked "fixed" are not in that list.

Anywhere#

These are the commands in Settings → Keyboard, grouped as the cheatsheet groups them.

Navigate#

KeysCommand
⌘KCommand palette
⌘PGo to file or doc
⌘⇧FSearch docs and files
⌘⇧KGo to Home
⌘⇧OOperations
⌘JAsk AI
⌘⇧JThe session that has waited on you longest; again for the next. After the sessions come tasks waiting on you, then back to the first session
⌘[ and ⌘]Back and Forward
⌘\ and ⌘⇧\Switch to next workspace and Switch to previous workspace
⌃⇥ and ⌃⇧⇥Next tab and Previous tab, by recency while ⌃ is held: once is the tab you were just on, twice the one before
⌘1 to ⌘9Go to tab 1‥9; with fewer than n tabs open, the last one
⌘WClose tab. A pinned tab refuses: unpin it first. Every close spares pinned tabs
⌘⇧TReopen closed tab
⌥⌘← and ⌥⌘→Move tab left and Move tab right
⌘⇧DOpen tab beside, such as a session beside its plan doc (⌘-click does the same; also on a doc in the tree, Favorites and Recents, a link in a doc, and Open beside in a doc's right-click menu)
⇧⌘\\Close split view

Tabs and the mouse#

These gestures are fixed. See Tabs for the rules.

GestureWhat it does
⌘-click a tab, a doc or a linkOpen it beside the current tab
Double-click a tabKeep a temporary tab open
Middle-click a tabClose it
Drag a tabReorder it; pinned tabs stay at the front
Right-click a tabKeep open, pin, open beside, close, close others, close to the right, close all
Drag the line between two columnsWiden one column; double-click equalises all
Arrow keys on that lineResize it in steps of 16 px; Shift makes the step 64 px

Terminal#

Over a focused terminal, every ⌘ chord belongs to the app except these. On Windows and Linux the app's chord is Ctrl+Shift, and plain Ctrl keys go to the CLI. See The terminal.

KeysWhat it does
⌘FSearch the session, scrollback included
⌘CCopy the selection; without one, the app's own meaning
⌘VPaste
⌘+ / ⌘− / ⌘0Zoom the terminal font in, out, and reset it (remembered)
⌥⌘KClear
Shift+EnterNew line in the prompt, without sending
⌥← / ⌥→ / ⌥⌫Jump a word left, right; remove a word
Ctrl-CInterrupt, sent to the CLI

Files and the editor#

In a file (Reading a file):

KeysWhat it does
⌘SSave
⌘FSearch the file
⌥HOpen the file's history
[ and ]Step through changes (not while typing)
⌥1 and ⌥2Switch between Preview and Read, on a Markdown or SVG file (the code holds up to four forms; today only these two exist)
EscapeLeave Diff or a past commit

Ctrl+GGo to line
⌘/Comment

⇧⌥↑ / ⇧⌥↓Copy a line
⇧⌘KRemove a line

Home#

Arrow keys turn the deck of cards on Home; left and right step back and forward.
