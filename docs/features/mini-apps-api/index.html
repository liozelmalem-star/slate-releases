App API

What a app can import from Slate. Your AI tool gets all of this as TypeScript declarations when it reads the app, and Slate checks every save against the same declarations, so a call that is not on this page is an error before the app runs. The Files editor completes from them as you type.

import { createRoot } from "react-dom/client";
import { slate } from "@slate/sdk";
import { count, dayLabel } from "@slate/sdk/format";
import { useQuery } from "@slate/sdk/react";
import { BarList, Badge, Card, Page, QueryView, Section } from "@slate/ui";

function App() {
  const week = useQuery(() => slate.sessions.count({ days: 7 }));
  return (
    <QueryView query={week} isEmpty={(d) => d.total === 0} empty="No AI sessions this week.">
      {(d) => (
        <Page title="AI sessions this week" actions={<Badge tone="active">{count(d.total, "session")}</Badge>}>
          <Section title="Per day">
            <Card>
              <BarList rows={d.byDay.map((x) => ({ label: dayLabel(x.day), value: x.count }))} />
            </Card>
          </Section>
        </Page>
      )}
    </QueryView>
  );
}

createRoot(document.getElementById("root")!).render(<App />);

Your AI tool sees three whole examples like this one, a chart, a list and a form, and Slate builds each of them in its own tests.

@slate/sdk

Everything here reads or acts inside the app's own project. since is one of "1d", "7d", "30d" or "90d". Every list returns newest first, at most limit rows; to read on, pass the last row's time as before.

Reading

CallWhat it returns
slate.project.get()The project's id and name.
slate.pages.list({ limit })The project's pages, newest first, each with its kind: group, project, branch, a document, a session.
slate.pages.get(id)One page with its text.
slate.memories.list({ limit })The project's memories, newest first.
slate.memories.search(text)Memories holding every word of text.
slate.sessions.list({ since, limit })AI sessions recorded in the project: tool, date, title, summary.
slate.sessions.count({ days })Session counts per day (default 7 days, at most 90) and per tool, for a chart.
slate.sessions.live()The AI sessions running in the project now: working, waiting or idle.
slate.usage.list({ since, limit })AI runs in the project (default the last 30 days): tool, model, time, prompts, tokens and cost.
slate.activity.list({ since, kinds, limit })Git activity in the project's folders (default the last 7 days): commits with their message, branches made, switched and deleted, files staged.
slate.artifacts.list({ limit })The project's artifacts, this app included, each with a link to open it.
slate.routines.list()The routines the project can run.

An app asks for a permission in its slate.json:

{ "permissions": [{ "use": "tasks.write", "why": "Move a review to tomorrow" }] }

The permissions are tasks.read, tasks.write, memories.write, pages.write, routines.run and sessions.start. A refused call throws a SlateError whose code says why: not_allowed (the app did not ask), not_granted (you have not allowed it yet), bad_request, failed or no_answer.

Its own data

slate.store.get(key), set(key, value), delete(key) and keys() keep the app's own data on this Mac, never synced, up to 1 MB.

slate.on(area, fn) calls fn when Slate's data changes in that area: "pages", "memories", "tasks", "sessions" or "activity", or "changed" for every change. An area also hears a change Slate cannot name.

@slate/sdk/react

HookWhat it does
useQuery(load, deps, { on })Reads with load and returns { data, loading, error, refresh }. It keeps the last answer while it reads again, and reads again by itself when pages, memories or tasks change. A live view adds on: ["sessions", "activity"].
useStore(key, initial)One value of the app's own data, as [value, setValue], saved as it changes.

@slate/ui

Slate's own parts, in its light and dark themes:

  • Page layout: Page (a title, a line under it, the page's buttons), Section (a part under its label), Grid (cards side by side that wrap), Header, SectionLabel
  • A read's states: QueryView takes what useQuery returned and shows the wait, an error with Retry, your words when there is nothing, or your screen
  • Charts and numbers: BarList (labelled bars to one scale), Sparkline, StatCard (a number and how it moved), RankedList
  • Controls: Button, IconButton, Input, Textarea, Select, Checkbox, Switch, Segmented
  • Display: Badge, Chip, Avatar, Kbd, When (a time like "3h ago")
  • Frames and lists: Card, Row
  • States: Callout, EmptyState, ErrorState, Loading, Spinner, Skeleton, SkeletonLines

react, react-dom/client and lucide-react (every icon) are there as usual.
