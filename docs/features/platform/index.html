Platform & Availability

Slate is a native desktop app built on Tauri 2 with a Rust host and a React 19 webview. The published bundle is one universal macOS app, for Apple Silicon and Intel Macs. Each release also tries to build a Linux .deb and a Windows installer, and attaches each one only when its build passes. No release has carried either yet. Everything below separates what you can download from what is built and what is only planned.

macOS on Apple Silicon is where Slate is developed and tested every day. Linux has been built and checked in a clean Ubuntu machine: the gate's boot step, the tests, and the window's network seal. On Linux the shortcuts read Ctrl instead of ⌘, closing the window minimizes it, and the tray icon has a menu (Open Slate, Quit Slate) because a Linux tray reports no clicks.

There is nothing to run on Windows today. Releases are cut by hand on an Apple Silicon Mac, which also builds the Intel half; the Linux .deb (and, once published, the Windows installer) is built on a GitHub runner and signed on that Mac. Treat the Windows row as a plan, not an option.

How you install it

One way: the curl command in Getting Started, which downloads the prebuilt app, checks its checksum (when the release lists one) and puts it in /Applications. There is no Homebrew cask, no App Store listing and no AppImage — none of them is built. A .deb or a Windows installer is downloaded from the release page when a release carries one; the site's README says which the latest release has.

A release also carries a .dmg (Slate_<version>_universal.dmg), and it is not the supported path. Slate is not notarized by Apple, and macOS quarantines whatever a browser downloads — so opening that disk image gets you "Apple could not verify Slate is free of malware", which on macOS 15 and later can only be cleared in System Settings → Privacy & Security. curl sets no quarantine flag, which is the whole reason the installer is a script. Use the .dmg only if you already know what you are clearing.

How you remove it

The matching curl command — see Uninstalling. It takes Slate out of the AI tools it installed itself into, removes the app, and keeps your workspace unless you ask it not to.
