Features

Platform & Availability

Slate is a native desktop app: Tauri 2, a Rust host and a React 19 webview. Each Mac CPU has its own app, one for Apple Silicon and one for Intel. Releases up to 0.1.54 shipped one universal app, and an installed universal copy updates to its own CPU's app. Each release also builds a Linux .deb and a Windows installer on GitHub's runners, and attaches each only when its build passes. Linux and Windows are early builds: they boot and pass their tests, but nobody uses them day to day, and finishing the Windows port is still open (issue #138). The table is written from the latest release's files each time the guide is published.

Slate needs macOS 13.5 (Ventura) or later. Its bundled server is Node 24, and LSMinimumSystemVersion in Info.plist makes an older Mac refuse to open the app instead of showing a window with no server.

Slate is developed and tested daily on macOS, Apple Silicon. For Linux, each release's platform build runs the Rust tests on a GitHub Ubuntu 22.04 runner, builds the .deb, installs it and waits up to 60 seconds for the app to log that it started. On Linux:

  • shortcuts read Ctrl instead of ⌘
  • closing the window minimizes it
  • the tray icon has a menu (Open Slate, Quit Slate), because a Linux tray reports no clicks
  • Slate watches a project and your agents' transcript folders one folder at a time, never inside build output such as node_modules or dist. It uses at most a quarter of fs.inotify.max_user_watches, and no more than 8,192. At the cap it says so once in its log and stops adding folders. Git and the periodic checks still see changes there.

Releases are cut by hand on an Apple Silicon Mac, which also builds the Intel app. It signs the Linux .deb and the Windows installer with the same updater key.

How you install it

Run the curl command in Getting Started. It downloads the prebuilt app, checks its checksum and code signature, and puts it in /Applications. A missing or wrong checksum, or a signature other than Slate's own certificate, stops the install. There is no Homebrew cask, App Store listing or AppImage. A .deb or Windows installer is downloaded from the GitHub release when it carries one. The site's README says which the latest release has.

Each release also carries one .dmg per CPU (Slate_<version>_aarch64.dmg, Slate_<version>_x64.dmg). It is not the supported path. Slate is signed with its own self-signed certificate and is not notarized by Apple, and macOS quarantines whatever a browser downloads, so the image opens with "Apple could not verify Slate is free of malware". On macOS 15 and later only System Settings → Privacy & Security clears that. curl sets no quarantine flag, which is why the installer is a script. Use the .dmg only if you know what you are clearing.

How you remove it

Run the matching curl command in Uninstalling. It takes Slate out of the agents it installed itself into, removes the app, and keeps your workspace unless you ask otherwise.
