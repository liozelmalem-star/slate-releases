Platform & Availability

Slate is a native desktop app built on Tauri 2 with a Rust host and a React 19 webview. The same codebase targets macOS, Linux and Windows — but only one bundle has ever been built and published: macOS on Apple Silicon. Everything below distinguishes what the stack supports from what you can actually download.

Platform support today

PlatformCan you download it?Status
macOS, Apple SiliconYes — Slate_<version>_aarch64.dmgPrimary platform, smoke-tested
macOS, IntelNo buildThe stack supports it; none has been produced
LinuxNo buildLikely works; not the primary target
WindowsNo buildSupported by the stack, but not smoke-tested

macOS on Apple Silicon is where Slate is developed and exercised, and it is the only bundle any release has carried. The stack (Tauri, node:sqlite, the SEA sidecars) is cross-platform, so the others are expected to work — but "supported by the stack" is not the same as "built", and none of them has been.

There is nothing to run on Windows, Linux or an Intel Mac today. The release workflow has a Windows job that has never executed, and releases are cut locally on Apple Silicon. Treat every non-Apple-Silicon row above as a plan, not an option.

Distribution channels

How you'll install Slate is phased. The plan:

PhaseChannel
P0Direct download via GitHub Releases
P1Homebrew cask + Windows
P2macOS App Store + Linux AppImage / Flatpak

Distribution is roadmap. Direct download from GitHub Releases is the first target (P0); package managers and stores come later.
