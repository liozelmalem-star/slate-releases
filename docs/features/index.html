Features

Every part of the shipped product, one page each.

Pages & the Block Editor Everything in Slate is a page — nested, typed, and edited in a keyboard-first block editor backed by a single SQLite table. Typed Documents & Hierarchy A page's doc_type pre-fills a template, tracks a status, and slots it into the project → repo → branch hierarchy that lets memory tools resolve targets. Missions A mission is a first-class typed page for a unit of work — a status dot, a session log, and a home for progress that AI tools append as they go. Search & Command Palette One keystroke to run any action, jump to any page, or full-text search your whole workspace — plus a cheatsheet and rebindable shortcuts. Memory Slate's memory is a shared, cross-tool layer — an MCP server every AI tool can read and write, populated automatically, and readable by hand as pages. Session Capture Slate auto-captures your AI sessions from Claude, Codex, Gemini, Cursor and OpenCode — a filesystem watcher for the tools that write transcripts, a database reader for the one that doesn't. No hooks, no manual logging. Recall & Remember The two core verbs of Slate's memory — recall context at the start of a task, remember what you learned at the end. Decisions & Facts Two kinds of durable memory — decisions are logged choices with rationale, facts are persistent pieces of knowledge ranked for recall. Memory Map A visual view of your facts and decisions as a map — places you can learn, rather than a picture you re-read every time. The AI Console Slate's in-app AI agent — the Console. It reads and writes your workspace and reaches the MCP tools you connect, with the intelligence pushed into code. Brains & Model Providers Slate calls its model providers "brains" — thin drivers over a locally-installed CLI, so there's no API key to paste and nothing leaks through a raw API. Curated MCP Commands The mechanism behind the Console: keyword routing resolves a tool, the app prefills known args, and the model fills only the rest via structured output. Connected MCP Tools The Console reaches every MCP server the brain's own CLI declares. Not to be confused with Slate as an MCP server. Slate as an MCP Server Slate's second identity — a Node stdio MCP server that exposes your workspace and memory to any AI tool, backed by a shared recall/remember contract. Tool Reference The full grouped tool surface of Slate's MCP server — pages, memory, activity, decisions, tickets, and capability discovery — with target resolution and dry_run. Connecting Your AI Tools Wire Claude Code, Cursor, Codex, Gemini or OpenCode to Slate's MCP server so every tool shares the same memory — from the app in three clicks, or by hand. Workspaces A workspace is a whole store, shared or private. Switch into one in the sidebar and the entire app is in it — pages, memory, activity, search. Working in a Shared Workspace Inside a shared workspace, everything is shared — that is what the container means. What read-only protects, and how the replica stays in step. Workspaces & Invites Accounts, workspaces, roles and the invitation that gets somebody in — plus what a role actually controls, on the server and on your machine. Studio Write your instructions and skills once, then sync them to every AI tool you use — Claude Code, Cursor, Codex, Gemini and OpenCode — from one source of truth. CLI Config Profiles Each project decides which AI tools it uses and the account each one runs under — so work stays on the work login and personal work stays personal, including sessions you start yourself in a terminal. Agents & Workflows Scheduled background agents that wake on a cron-like cadence, gather your recent context, and run the model with tools — plus multi-step workflows they can trigger. Sessions — the Live Tracker Every AI-CLI session on your machine, live — who's working, who's blocked on you, and the projects-×-brains map behind them. Activity & Analytics A view of your captured work over time — session history, a daily brief, per-project activity, and the charts and stats built from it. Connect One place for everything this workspace reaches outside itself — which AI tools it runs, what they can see, and what runs on its own. Automations Everything Slate does when you are not asking it to — what each one is for, and how to switch any of them off. Themes Slate's four themes — a coloured pair and a monochrome pair — the accent choice, and where colour shows up across the interface. Privacy & Security Slate keeps your workspace on your machine. Nothing leaves without an explicit action — and there are only four exceptions. Your Data & Export Your whole workspace is one SQLite file on your machine. Export is a copy, the format is open, and your data outlives the app. Licensing & Updates The planned licensing model and the Tauri auto-updater. Most of this is roadmap, not shipped — read the hint blocks. Platform & Availability Which platforms Slate runs on today, and the planned distribution channels for getting it installed.
