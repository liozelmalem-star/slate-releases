Documentation

Features

Every part of the shipped product, one page each.

Pages & the Block Editor Everything in Slate is a page — nested, typed, and edited in a keyboard-first block editor backed by a single SQLite table. Typed Documents & Hierarchy A page's doc_type pre-fills a template, tracks a status, and slots it into the project → repo → branch hierarchy that lets memory tools resolve targets. Missions A mission is a first-class typed page for a unit of work — a status dot, a session log, and a home for progress that AI tools append as they go. Search & Command Palette One keystroke to run any action, jump to any page, or full-text search your whole workspace — plus a cheatsheet and rebindable shortcuts. Memory Slate's memory is a shared, cross-tool layer — an MCP server every AI tool can read and write, populated automatically, and readable by hand as pages. Session Capture Slate auto-captures your AI sessions from Claude, Codex, Gemini, Cursor and OpenCode — a filesystem watcher for the tools that write transcripts, a database reader for the one that doesn't. No hooks, no manual logging. Recall & Remember How memory reaches an AI session — an index at the start, a search the agent runs, and a lesson on the tool call it is about — and how the session saves, cites and corrects what it learned. Decisions & Facts Two kinds of durable memory — decisions are logged choices with rationale, facts are persistent pieces of knowledge ranked for recall. Memory Map A visual view of your facts and decisions as a map — places you can learn, rather than a picture you re-read every time. The AI Console Slate's in-app AI agent — the Console. It reads and writes your workspace and reaches the MCP tools you connect, with the intelligence pushed into code. Brains & Model Providers Slate calls its model providers "brains" — thin drivers over a locally-installed CLI, so there's no API key to paste and nothing leaks through a raw API. Features by AI Tool Which AI tool has which feature in Slate, and why a gap is there — the one table every per-tool control reads. Curated MCP Commands The mechanism behind the Console: keyword routing picks one of Slate's own tools, the app prefills known args, and the model fills only the rest. Connected MCP Tools The Console reaches every MCP server the brain's own CLI declares. Not to be confused with Slate as an MCP server. Slate as an MCP Server Slate's second identity — a Node stdio MCP server that exposes your workspace and memory to any AI tool, backed by a shared recall/remember contract. Tool Reference Every tool Slate's MCP server exposes — pages, memory, workspaces, activity, decisions, tickets and capability discovery — with their arguments and defaults. Connecting Your AI Tools Wire Claude Code, Cursor, Codex, Gemini or OpenCode to Slate's MCP server so every tool shares the same memory — from the app in three clicks, or by hand. Workspaces A workspace is a whole store, shared or private. Switch into one from the top of the rail and the entire app is in it — pages, memory, activity, search. Working in a Shared Workspace Inside a shared workspace, everything is shared — that is what the container means. Moving work in, what read-only protects, and how memory travels. Workspaces & Invites Accounts, workspaces, roles and the invitation that gets somebody in — plus what a role actually controls, on the server and on your machine. Studio Write your instructions and skills once, then sync them to every AI tool you use — Claude Code, Cursor, Codex, Gemini and OpenCode — from one source of truth. Project environments Which AI tools a workspace runs and the account each one runs under — so work stays on the work login and personal work stays personal, including sessions you start yourself in a terminal. Loop & Routines Routines — something that runs on a trigger and does steps — and Loop, where you set them up, run them and read every report they write. Sessions — the Live Tracker Every AI-CLI session on your machine, live — who's working, who's blocked on you, and where each one runs. Work Work — everything waiting on you, in three sections: Solve, Review and Reply. What your tools report, the lines you write yourself, and a reminder on any of them. Activity & Analytics A view of your captured work over time — session history, per-project activity, and the charts and stats built from it. Connect One place for everything this workspace reaches outside itself — which AI tools it runs, what they can see, and what runs on its own. Automations Everything Slate does when you are not asking it to — what each one is for, and how to switch any of them off. Themes Slate's four themes — a coloured pair and a monochrome pair — the accent choice, how big the interface is, and where colour shows up across it. Privacy & Security Slate keeps your workspace on your machine. Nothing leaves without an explicit action — and there are only four exceptions. Your Data & Export Your whole workspace is one SQLite file on your machine. Export is a copy, the format is open, and your data outlives the app. Licensing & Updates Nothing to license yet, and how the Tauri auto-updater installs a new version without interrupting you. Platform & Availability Which platforms Slate runs on today, and which have never been built.

Slate is in alpha. Your data stays on your machine.
