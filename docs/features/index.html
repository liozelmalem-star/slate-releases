Documentation

Features

Every part of the shipped product, one page each.

Docs & the Block Editor Everything in Slate is a doc: nested, typed, and edited in a keyboard-first block editor. Covers the editor, the doc tree, Code, Trash, and the group, project and branch docs. Typed Docs & Hierarchy A doc's doc_type pre-fills a template. Its status tracks progress. Both place it in the group, project, branch hierarchy that lets memory tools resolve targets. Missions The `mission` doc is a legacy type that the branch doc replaced. Also covers how agents log progress on a branch and how Slate offers a doc at each milestone. Search & Command Palette Press ⌘K to run an action, jump to a doc or search your workspace. Also the cheatsheet, rebindable shortcuts, the sidebar, the rail and tabs. Memory Slate's memory is shared by every agent through an MCP server, filled in automatically, and stored as docs you can read and fix. Session Capture Slate captures your AI sessions from 16 agents, by watching transcript files or reading a tool's own database. Recall & Remember How memory reaches an AI session (an index at the start, a search, a lesson on the tool call) and how the session saves, cites and corrects what it learned. Decisions & Memories Two kinds of durable memory: decisions are logged choices with their reasoning, other memories are lasting knowledge ranked for recall. Memory Graph A map of your memories on the files they are about, coloured by whether your sessions use them, with a list to read, search, correct and retire them. Home Home, Slate's in-app AI agent: it reads and writes your workspace, reaches the MCP tools you connect, and does its routing in code so a light model works. Agents & Model Providers The 16 agents Slate drives, each a thin driver over a CLI you already have installed and signed in to, so there is no API key to paste. Features by Agent Which agent has which feature in Slate, and why a gap is there. Every per-tool control reads this one table. Curated MCP Commands How Home works on a light model: keyword routing picks one of Slate's own tools, the app prefills known args, and the model fills only the rest. Connected MCP Tools Home reaches every MCP server the agent's own CLI declares. Not the same as Slate as an MCP server. Slate as an MCP Server Slate as an MCP server: one local server that gives every agent the same workspace and memory, under a recall / remember contract. Tool Reference Every tool Slate's MCP server exposes, with arguments and defaults: docs, memory, workspaces, activity, your Tasks list, connected apps, other agents, decisions, artifacts, apps, setup, agent runs and capability discovery. Connecting Your Agents Connect any of 16 agents to Slate's MCP server: from the app, or by hand. Workspaces A workspace is one store, shared or private. Switch into one from the top of the rail and the whole app works inside it. Working in a Shared Workspace Inside a shared workspace everything is shared. How to move work in, what read-only means, and how memory and artifacts travel. Workspaces & Invites Accounts, workspaces, roles and invitations, and what a role controls on the server and on your machine. Toolkit Write your instructions and skills once, then sync them to your agents from one source. Project environments Which account each agent runs under, per workspace and per group or project, so work stays on the work login. Covers sessions you start yourself in a terminal. Automations Automations work for you on a trigger, inside rules you set. Give one a job, reply in its thread, and say yes or no before it changes anything. Built-in automations The thirteen things Slate does on its own, what each is for, and how to switch them off. Sessions — the Live Tracker Every AI-CLI session on this machine, live. Who is working, who needs you, where each runs, and what each changed. Tasks Tasks — what waits on you, in four sections (To-dos, Issues, Reviews, Messages), plus today's meetings, reminders, agent runs and receipts. Artifacts Web pages your agents publish for you: an HTML page, chart, report or Markdown note, kept in your workspace with every version. Apps Apps are small programs your agent builds inside Slate. They read your workspace, act only through permissions you allow, and have no internet. Build, change, restore and trash them here. App API Every call, hook and part an app can import from Slate, with what each one returns and which permission it needs. Activity & Analytics Your AI sessions over time: the dashboard, where its numbers come from, and how far back it reaches. Trash Docs and apps you move to Trash stay there until you restore them or delete them forever. Connect The screen for how a workspace reaches outside itself: which agents it runs, and which apps it connects. Settings What each Settings tab holds. Every tab is about this computer; what one workspace allows is in Connect. Themes Slate's four themes (a coloured pair and a monochrome pair), the accent, and the interface zoom. Privacy & Security Slate keeps your workspace on your machine. Four things can send data out, plus the connections you set up yourself. Each is listed below with how to turn it off. Your Data & Export Each workspace is one SQLite file on your machine. Export is a copy, the format is open, and your data outlives the app. Licensing & Updates Free during the alpha, paid soon. How updates arrive in steps, install when you quit, and what safe mode does. Platform & Availability Which platforms Slate runs on today, which are built but not yet published, and how you install and remove it. What Slate Costs Your Machine The most CPU, memory and disk Slate may use on your Mac, how the tests measure it, and how to check it yourself.

Slate is in alpha. Your data stays on your machine.
