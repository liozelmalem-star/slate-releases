# Projects

**Projects** is where the work of each project lives: the plans, designs, reviews, bugs and
notes written in it, and its code. A project is one folder you open, usually a
git repository. A group is a set of projects you name.

## Docs and Code

The side panel has two tabs:

- **Docs** lists each project's docs in a tree, by type ([The doc tree](https://liozelmalem-star.github.io/slate-releases/docs/features/projects/tree.md)).
- **Code** lists each project's files and the changes waiting to be committed
  ([Files and changes](https://liozelmalem-star.github.io/slate-releases/docs/features/projects/code.md)).

Every launch starts on **Docs**. The choice lasts while the app is open.

With nothing open, Projects opens something for you: the doc you read last in the
picked project, or its README the first time ([Nothing open](https://liozelmalem-star.github.io/slate-releases/docs/features/projects/tree.md#nothing-open)).

## Narrow to one project

The **project picker** under the panel's tabs narrows the list to one project. It reads
**All projects** at rest. A picked project shows its name with **×** to go back. The
choice lasts while the app is open, and every launch starts on **All projects**.

## Make a project

- The **+** in the panel's title row: **New project…**. Choose a folder; the name comes
  from it.
- The workspace mark at the top of the rail: **New project…** and **Manage projects…**.
  **Manage projects…** lists the workspace's projects by group, with **Rename**,
  **Show in Projects** and **Move to Trash**.
- **Import**, the down arrow beside the **+**: on its **Code** tab, the folders your
  editors opened lately (VS Code, Cursor, Windsurf, JetBrains IDEs); on its **Docs** tab,
  docs you keep in other apps. Slate shows what it found before it adds anything
  ([Import](https://liozelmalem-star.github.io/slate-releases/docs/features/connect/import.md)).

To put two or more projects in a group, shift-click them and choose **Group…** on the
⋯ menu ([Order, move and group](https://liozelmalem-star.github.io/slate-releases/docs/features/projects/tree.md#order-move-and-group)).

## A project's menu

A group or a project is a folder in the list. Clicking its row opens or closes it; only a
doc opens in the main area. Its **⋯** menu (or a right-click) offers:

| Item | What it does |
| --- | --- |
| **Start session** | Starts a session in the project. In a git project it starts in a new worktree ([Worktrees](https://liozelmalem-star.github.io/slate-releases/docs/features/sessions/worktrees.md)) |
| **Open a Terminal here** | Opens a terminal in its folder |
| **Show code** | Switches the panel to **Code** with this project's files open |
| **Link a folder** / **Change folder** | Sets the folder on this computer |
| **Settings…** | A group's, or a project's that is in no group ([Group and project settings](https://liozelmalem-star.github.io/slate-releases/docs/features/projects/settings.md)) |

A project in a group uses its group's settings.

## Favorites

**Add to Favorites** on a doc's menu puts it in **Favorites** at the top of the Docs list.
**Remove from Favorites** takes it off.

## What a workspace holds

A doc stays in the workspace it was made in. No doc, project or memory moves between
workspaces. Which workspace holds a doc decides whether it is shared
([Working in a shared workspace](https://liozelmalem-star.github.io/slate-releases/docs/features/workspaces/sharing.md)).

A project's sessions are in [Sessions](https://liozelmalem-star.github.io/slate-releases/docs/features/sessions.md), its memories in
[Memory](https://liozelmalem-star.github.io/slate-releases/docs/features/memory.md).
