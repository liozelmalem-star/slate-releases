Licensing & Updates

Licensing

Slate is free during the alpha. It has no licence, key or trial timer, and nothing in the app asks you to activate anything.

Slate will become paid soon. Pricing is announced on the website before it starts. Your workspace stays yours either way: it is a SQLite file on your machine, and you can always open and export it.

Auto-updates

Updates use Tauri's updater. It asks Slate's update service first, and the release manifest on GitHub Releases if the service does not answer. The files always come from GitHub Releases.

A release reaches people in steps. The service can offer a release to part of the installed copies first, and stop offering one that turns out bad. If Slate already downloaded a stopped version, it does not install it when you quit. To place your copy in a group, each check sends a random install id (see Privacy). A prerelease build also gets the next prerelease. A release build gets releases only.

Slate checks eight seconds after it opens, then every four hours while it stays open. It downloads in the background and tells you the update is ready. Nothing is installed yet.

On a Mac, an update usually downloads only what changed. A release carries a small patch from the version before it, about 5% of the full download (6 MB instead of 126 MB from 0.1.53 to 0.1.54). Slate rebuilds the new version from the patch and a kept copy of your current version, and installs it only if the result is exactly the published release and its signature checks out. Otherwise it downloads the whole version. The kept copy is about 50 MB in Slate's cache folder. If macOS clears it, the next update is a full download.

The update installs when you next quit Slate. The notice also has Restart now, which tells you first how many CLI sessions are open. Quitting and Restart now treat sessions the same way. A Claude Code session is sent to the background: Slate types /bg into it, waits a moment, and it keeps running as a background job. A session from another tool is ended. A session that is already a background job keeps running.

Nothing restarts on its own, and nothing is installed while you work.

About in Settings shows your version, any waiting update with its full release notes, and Check now. If a check or install fails, it says why, with Try again. Its Website, Documentation and Source lines open in your browser.

If Slate won't start

After three launches in a row fail to reach a working window, the next one starts in safe mode. The server still runs. Everything else in the background is skipped: startup repairs, the task and automation schedulers, sync, auto-capture, reminders, keep-awake and the agent reconnect. One screen looks for an update at once and installs it. It says "No newer version is published yet." when there is none and "Could not check for updates" when the check fails. With Automatic updates off, it keeps showing "Looking for a newer version…". Your workspace file is never touched. Start normally tries a normal launch. Open logs shows the log folder.
