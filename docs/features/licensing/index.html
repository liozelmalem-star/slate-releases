Licensing & Updates

Licensing

There is no licence, no key and no trial timer in Slate today. Nothing in the app asks you to activate anything, and no code in it checks whether you have. A paid tier is planned for the commercial phase; when it arrives it will gate the memory layer and never the editor, and nothing you have written will become unwritable.

Auto-updates

Updates run through Tauri's updater, wired to GitHub Releases.

Slate checks for a newer version eight seconds after it opens, and again every four hours while it stays open. When it finds one it downloads it in the background and tells you it is ready. Nothing is installed at that moment.

The new version is put in place when you next quit Slate, which costs you nothing: the app is closing anyway. If you would rather have it now, the notice has a Restart now button. Because Slate hosts running CLI sessions, that button tells you how many are open before you press it — quitting normally ends them too, so the only difference is when.

Nothing restarts on its own, and nothing is installed while you are working.

The About pane in Settings shows your version, whether an update is waiting, and a Check now button if you don't want to wait for the next automatic check.

If Slate won't start

If three launches in a row fail to reach a working window, the next one starts in safe mode: the watcher, background agents and the login item are all skipped, and you get a single screen that looks for an update and installs it. Your workspace file is never touched by any of this. Safe mode also has a button for trying a normal start.
