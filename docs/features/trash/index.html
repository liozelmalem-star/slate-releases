Trash

View as markdownOpen the .md copy of this page

Trash holds the docs and widgets you moved there until you restore them or delete them forever. Open it from Trash in the left rail, above Settings.

What lands here#

  • A doc, with every doc inside it. Use ⋯ → Move to Trash in the Projects tree, or Move to Trash in the doc.
  • A widget. ⋯ → Move to Trash keeps every version. Nothing moves here by itself (Widgets).

Each row says when it was moved and where it came from: "Moved to Trash 5 minutes ago · from Acme". A doc that held others shows "N inside"; expand it to see them. Click a title to read it first.

Restore, or delete forever#

  • Restore puts the doc back where it was, with everything that went to the Trash with it. A doc inside it that you had moved to the Trash on its own, earlier, stays in the Trash. If its parent is in the Trash too, it stays there with it until the parent comes back.
  • Delete forever… asks first and cannot be undone. A doc's nested docs go with it. A widget loses every version and the data it kept.

Tick rows to act on several: Restore (N) and Delete forever (N). Select all ticks every row shown. With nothing ticked, Empty Trash deletes everything forever, after the same question.

Filter by title narrows the list. With a filter on, the button reads Delete forever · N shown and removes only the rows you can see forever.

In a shared workspace#

Trash belongs to the open workspace. Moving a doc you wrote to Trash removes it from every member's copy on their next sync. A teammate's doc under it stays; when you move yours forever, theirs moves up to your doc's parent (Working in a Shared Workspace).
