The tools every AI tool gains

Slate runs an MCP server on your machine. Point Claude Code, Cursor, Codex or Gemini at it — Slate does that itself on first launch — and each of them gains these 26 tools against the same workspace. Not a copy each. The same one.

26 tools · one workspace · nothing leaves your machine

Memory

The two every tool is told to call: one at the start of a task, one at the end. Everything else on this page is reach; these two are the point.

recall

Load context before starting a task. On a feature branch the first result is the branch brief — goal, open checklist, recent sessions, linked docs — then repo conventions and project facts.

remember

Save one durable thing as a typed knowledge atom (decision, preference, state, or fact), scoped to the project and deduped against what is already known.

record_decision

Record a decision with its full reasoning — what was chosen, what was rejected, and how confident you are. Writes both an atom and a structured page.

list_decisions

List recorded decisions with confidence and a one-line summary of the reasoning.

log_mission_progress

Append an end-of-session progress entry to the branch's Plan page.

Pages

The workspace itself — a tree of nested, typed pages. Every mutating tool here takes a dry_run flag that resolves and validates without applying.

create_page

Create a page, optionally nested, with an optional Markdown body.

create_document

Create a typed workspace document — design, plan, review, bug report — pre-filled with a structured template and linked to its branch.

get_page

Read a page: title, icon, breadcrumb path, and body as Markdown.

list_pages

List the child pages of a parent, or the top level.

search_pages

Find pages whose title matches a query.

search_content

Full-text search over titles and bodies, returning a matching snippet.

update_page

Change a page's title, icon, or whole body.

edit_page

Replace an exact Markdown substring in a body — a surgical edit rather than a rewrite.

append_to_page

Add Markdown to the end of a page.

move_page

Reparent a page and its subtree.

duplicate_page

Copy a page and everything under it.

archive_page

Move a page to Trash. Reversible from the app.

resolve_target

Work out which branch or knowledge page a target descriptor points at, without writing anything.

Activity

What you have actually been doing, across every tool — assembled from sessions Slate captured rather than from anything you had to log.

recent_activity

Recent AI sessions across all tools and projects, newest first.

activity_stats

Totals and breakdowns: sessions this week, which tool you use most, what Slate has learned.

list_projects

Tracked projects and repos, with session counts.

parked_work

Branches you left carrying uncommitted changes and never came back to — what git cannot tell you.

Workspaces

The only tools here that read anything other than your own machine. They need a cloud sign-in, they are read-only, and signed out they say so rather than returning an empty result that would read as “nobody shared anything”.

recall_workspaces

Search what other people published into the workspaces you belong to.

workspace_page

Read one shared page in full. Read-only — a page belongs to whoever wrote it.

Tickets & contract

get_ticket_context

Resolve a ticket id to its branch page and a structured progress summary, for drafting an update.

slate_capabilities

Handshake the contract: version, schema hash, mutation safety rules, and the supported tool list.

Two things worth knowing

Most tools don't need a page id. They take a target descriptor instead — a kind, a cwd, a branch, a doc type, a title — and resolve the page from it. Pair a target with dry_run and the tool resolves and validates without applying anything, so an agent can check what it is about to touch first.
This is not Slate's only tool list. These are the tools your own AI tools reach, over MCP. Slate's in-app Console and its scheduled routines call a second, in-process surface directly. The two lists differ on purpose in places — slate_capabilities means nothing in-process, and the tools that drive Slate's own windows are not an outside tool's to call.
